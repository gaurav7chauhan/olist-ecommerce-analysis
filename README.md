# Olist E-Commerce Analysis (PostgreSQL + Power BI)

An end-to-end analysis of about 100,000 orders from Olist, a Brazilian
online marketplace (2016-2018). I act as a data analyst answering
questions a business team would ask about revenue, customers,
delivery and reviews.

## Business Questions
1. How does monthly revenue change over time?
2. Which product categories earn the most revenue?
3. Which states have the most customers?
4. What percentage of orders are delivered late?
5. Do late deliveries get lower review scores?
6. What share of customers buy more than once?
7. Which sellers bring in the most revenue?
8. Which payment methods do customers use most?

## Dataset
Brazilian E-Commerce Public Dataset by Olist (Kaggle): 9 related
tables covering orders, items, payments, reviews, products, sellers,
customers and geolocation.

## Tools
- PostgreSQL and pgAdmin: data loading, cleaning and analysis
- Power BI: dashboard
- Git and GitHub: version control

## Project Structure
- `sql/`: SQL scripts, numbered in the order they should be run
- `docs/`: written notes and reports
- `dashboard/`: Power BI file and screenshots
